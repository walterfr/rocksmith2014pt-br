# Rocksmith 2014 Remastered - Tradução PT-BR

Projeto de tradução colaborativa do **Rocksmith 2014 Remastered (PC/Steam)** para o **Português do Brasil (PT-BR)**.

Este projeto traduziu mais de 20.000 linhas de texto, menus, missões, lições e modos de jogo (incluindo o Guitarcade, Score Attack, Riff Repeater e menus de afinação) para o nosso idioma, além de adaptar os termos musicais para o contexto correto (como *bend*, *hammer-on*, *pull-off*, *palhetada*, *escala* e afins).

## 🆕 Versão mais recente

A versão [v1.0.1](https://github.com/walterfr/rocksmith2014pt-br/releases/tag/v1.0.1) inclui uma revisão de textos da interface, dos menus e dos tutoriais, com ajustes de clareza e consistência em PT-BR.

## 📥 Como Instalar

A forma mais fácil de instalar a tradução é baixar o arquivo já compilado (`cache.psarc`) na aba de Releases do GitHub.

1. Acesse a aba de **[Releases](https://github.com/walterfr/rocksmith2014pt-br/releases)**.
2. Baixe o arquivo `cache.psarc` da versão mais recente.
3. Vá até o diretório de instalação do seu Rocksmith 2014 na Steam. O padrão é:
   `C:\Program Files (x86)\Steam\steamapps\common\Rocksmith2014`
4. **IMPORTANTE:** Faça um backup do seu `cache.psarc` original (renomeie para `cache.psarc.backup`).
5. Cole o arquivo `cache.psarc` baixado dentro da pasta, substituindo o original se necessário.
6. Inicie o jogo. Ele estará em Português do Brasil!

*(Nota: Certifique-se de que o jogo não esteja rodando antes de substituir o arquivo).*

## 🤝 Quer ajudar a melhorar?

A tradução já passou por revisões automáticas, mas alguns textos podem ficar estranhos no contexto do jogo, estourar o limite de tamanho da tela ou possuir erros de digitação. 

Qualquer pessoa pode contribuir sugerindo melhorias nos textos! Consulte o arquivo [CONTRIBUTING.md](CONTRIBUTING.md) para saber como corrigir um texto e enviar sua contribuição.

## ⚠️ Isenção de Responsabilidade

Este projeto é feito por fãs e não possui qualquer vínculo com a Ubisoft ou a Steam. Modificar arquivos do jogo é por sua conta e risco, mas este mod afeta **apenas os textos de interface** e não altera nada relacionado a progresso, conquistas ou proteção anti-trapaça.
